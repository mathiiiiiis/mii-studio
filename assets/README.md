# Assets

The mii.glb that is in the project is a mii I created in Mii Creator
you can simply replace it with your own in the following steps:

Open Mii Creator > Click the Mii you want export > "Export/Download Data" >
"Download 3D Model" > Leave options as-is and scroll down > Click "Export"

The downloaded file will have a name similiar to this:
mathis_all_body_2026-08-20T04_28_18.239Z.glb

Simply rename it to mii.glb or change the path in `mii-studio.config.json`
to use your name.
